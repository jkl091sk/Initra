# Initra — Linux Setup Manager

## Short description

Initra is a modern Linux setup and system-management desktop application that
combines software installation, updates, cleanup, diagnostics, profiles,
backups and system configuration in one interface.

## Portfolio description

Initra was designed as a unified control center for configuring and
maintaining a Linux workstation without jumping between multiple terminal
commands and system utilities.

The application automatically detects the current Linux distribution and
package manager and adapts supported actions for APT, DNF, pacman and zypper
systems. Its interface is organized into seven focused sections: Dashboard,
Setup, Software, System, Maintenance, Tools and Settings.

Key features include reusable setup profiles, distro-aware package management,
repository information, updates, system health diagnostics, selective storage
cleanup, configuration backups, GNOME tweaks, startup application management,
service controls, dotfiles tools, command preview, setup import/export and
Linux compatibility information.

Initra 3.1 adds smoother page and tab transitions, a refined pink dark visual
identity, improved package-manager compatibility and reliability fixes across
setup, maintenance, software, services, drivers and startup management.

The project is built with Python, PySide6 and Qt 6 and uses a custom dark
desktop interface.

**Version:** 3.1.0
