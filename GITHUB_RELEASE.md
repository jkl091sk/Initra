# Initra 3.0 Stable

The first stable release of Initra Linux Setup Manager.

### Highlights
- Clean seven-section navigation
- Automatic Linux distribution detection
- APT / DNF / pacman / zypper compatibility layer
- Setup profiles and Command Preview
- Software, updates and repository tools
- Health Check and diagnostics
- Backup & Restore
- Selective Cleanup
- Tweaks, Startup Apps and Services
- Import/export tools
- Application-menu installer

### Install

Extract the archive and run:

```bash
chmod +x install_desktop.sh
./install_desktop.sh
```

Or run directly from a Python virtual environment as described in the README.
