# Initra 3.0 Stable

Initra 3.0 is the first stable release of the redesigned Linux Setup Manager.

The release consolidates the application into seven top-level sections and
adds a Linux compatibility layer capable of detecting the current
distribution and selecting package-management behavior for APT, DNF, pacman
and zypper systems.

Highlights include Profiles, Command Preview, Software management, Updates,
Repositories, Health Check, Backup & Restore, selective Cleanup, system
Tweaks, Startup Apps, Services, Drivers, Dotfiles, History and a first-run
wizard.

Ubuntu/Debian-family support remains the most mature path because Initra
originated as an Ubuntu-focused application. Distribution-specific features
remain capability-aware instead of blindly executing Ubuntu commands on other
Linux distributions.

Version: 3.0.0
Channel: Stable
