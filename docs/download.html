Initra 3.1.0

The v3.1 code is ready for final local verification. The release archive will appear on GitHub Releases after the runtime check and tag are published.

1. Get the source

Until the v3.1 release archive is published, clone the current repository to test the release candidate.

$ git clone https://github.com/jkl091sk/Initra.git
$ cd Initra
Open GitHub

2. Install Initra

Run the included desktop installer. It installs Initra for your user, adds the icon and creates an application-menu shortcut.

$ chmod +x install_desktop.sh
$ ./install_desktop.sh
Installation guide

3. Launch

Open your Linux application menu, search for Initra, and launch it. You can then pin it to your dock or favorites.

Applications → Initra
