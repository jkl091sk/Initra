Getting started

The recommended way to use Initra is to download the stable release and install it into your Linux application menu.

1. Download and extract

Download Initra 3.0.0 Stable from the Download page, extract the archive, then open a terminal in the extracted Initra folder.

$ unzip Initra-3.0.0-Stable.zip
$ cd Initra

2. Install Initra

Make the included installer executable and run it:

$ chmod +x install_desktop.sh
$ ./install_desktop.sh
What this does
Initra is installed for your user, its icon is added, and a desktop application entry is created so you can launch it from your application menu.

3. Launch Initra

Open your Linux application menu and search for Initra. Launch it like any other desktop application. You can also pin Initra to your dock or favorites.

4. Choose a profile

Use a setup profile as a starting point, then review and adjust the selected items for your system.

Tip
Use Command Preview / Dry Run to inspect generated commands before applying changes.

5. Review and apply

Check the plan before applying it. Progress and history help you understand what Initra changed.

Run from source instead

Developers can also run Initra directly from the repository without installing a desktop shortcut:

$ git clone https://github.com/jkl091sk/Initra.git
$ cd Initra
$ python3 -m venv .venv
$ source .venv/bin/activate
$ pip install -r requirements.txt
$ python main.py
